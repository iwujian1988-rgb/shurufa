# 英语与法语伴学输入法项目

当前迭代为 0.5.0-demo：九宫格改为大号 ABC、DEF 等字母组，优化候选复用、按需加载和解码查询。英语同机固定测试候选首次绘制 p95 约从 181ms 降至 71ms；此为试打页测试，不代表所有应用。两包已构建、覆盖安装，最新证据见 deliverables/九宫格字母与性能验收记录.md。英语/法语词库内容沿用 0.4，尚未独立语言校审。

0.4 历史迭代：英语也支持按读音整理的常用词、会话、长按学习详情；两包共用更高的九宫格，应用内可选紧凑/舒适/加大。英语方案见 docs/ENGLISH_DICTIONARY_PLAN.md。最终验收见 deliverables/英语与键盘高度验收记录.md，旧 0.3 验收属于历史。全部语言数据仍未完成独立编辑校审。


本项目计划基于青简 Qingjian 开源输入法，开发英语与法语两个独立产品。用户照常输入中文，在候选词旁接触目标语言译词。首期交付安卓，长期支持 Windows、iOS 和 macOS。

0.3 历史里程碑：暂名“词伴”，英法双包共用 Kotlin 客户端与 Rust 核心，可并存，支持全键与九宫格。新增法语读音词典、会话短语及长按学习详情，并验证手机新数据与学习迁移。0.1/0.2 验收是历史基线，当时结果见法语词库验收记录；全面兼容和正式发布尚未完成。
