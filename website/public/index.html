WHY CIBAN / 为什么词伴

让熟悉的生活，
带你接近陌生的单词。

词伴的想法很简单：
学习不必每次都从打开另一个 App 开始。

01

多次遇见，比只看一次多一份机会

你常打的“朋友”“学习”“咖啡”，可以成为反复接触外语词汇的入口。研究发现，重复遇见与词汇学习存在正相关；注意力、已有词汇量和接触方式也会影响结果。研究依据 ↗

02

从想表达的意思，连到外语词形

打中文时，你已经知道自己想说什么。候选旁的一行释义，让你有机会把熟悉的意思与英语或法语连起来。这是词伴的产品设计思路，具体学习效果仍需验证。

03

顺手接触，也可以多想一步

遇到感兴趣的词，先试着回想它的意思，再长按候选查看已整理的用法。日常接触可以补充系统学习；想真正掌握，仍需要主动回忆、练习与复习。

研究支持重复接触的学习价值，并不直接证明词伴的效果。我们还没有进行产品学习效果实验，也不承诺固定的记忆提升比例。

GOOD TO KNOW / 使用前了解

你可能还想知道。

我输入的是中文，还是外语？

仍然是中文。英语或法语释义显示在有对应释义的候选旁，帮助你顺手接触外语。点击候选不会自动把聊天内容改成外语。

它能翻译整句或任意词组吗？

当前支持词级释义和已整理的常用词组，不是整句翻译器，也不能保证所有自组词都有译文。部分释义仍需校审，请结合语境使用。

需要联网吗？输入内容会上传吗？

当前 APK 不申请网络权限，基本输入、词库查询与释义在本机运行。下载官网需要联网；验证下载码会暂存下载授权，不接收你在输入法里打的内容。

英语版、法语版可以一起装吗？

可以。两版是独立应用，可同时安装。启用后，在系统输入法选择器中切换“词伴 · 英语”或“词伴 · 法语”。

下载码可以重复使用吗？

不能。Android 与 Windows 共用额度，每个下载码只能领取一个语言版本的 APK 或 EXE，开始下载时立即核销；换浏览器、刷新或重新输入同一码都不能再次领取。仅验证、查看页面不消耗码。下载中断时，原浏览器可在 30 分钟授权期内续传同一文件，完成后不能重下。配套源码不占安装包次数，已用码仍可获取源码。专属链接也遵循同样规则。

Windows 版本有什么使用要求？

当前支持 Windows 11 x64，安装器为未签名测试包，可能出现未知发布者提示。请核对官网下载来源与 SHA-256；不要关闭安全防护。安装后打开词伴设置，按 Win + 空格选择对应输入法。系统安装、各应用兼容和升级体验仍需试用验证。

为什么 Android 提示安装来源或键盘权限？

这是直接安装 APK 和启用第三方输入法时的系统提示。请核对来源、文件校验值和应用名称。当前为测试签名版本；如果已有同名应用但签名不同，安装可能失败，请先备份个人数据再处理。
