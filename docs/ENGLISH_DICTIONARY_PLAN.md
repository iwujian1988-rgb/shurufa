# 英语词库与学习功能

2026-10-04，0.4.0-demo。本文件记录实际方案与边界，完整验证以 deliverables/英语与键盘高度验收记录.md 为准。

## 本轮授权

用户确认继续补齐英语的读音词义、常用短语与学习详情，并指出九宫格整体过矮、操作不便。两个包继续共享实现，分别安装。用户已授权升级连接的手机。

## 已实现的数据路径

保留固定青简发布数据中的 232,213 条英语释义，仍用于不涉及多个无声调读音的词头。新增独立 GPL-3.0-or-later 学习表 `english-lessons.qj`，键为“中文#候选无声调拼音”，不经法语翻译，也不导入 CFDICT 法语释义。只共享中文发音标识。

第一批独立 AI 编写数据包含 73 条常用词、144 条会话表达、101 条多音字/高频读音整理。合并后 317 条读音记录、280 个中文词/短语。常用学习信息提供已填写的词性、原形、可数性、不规则变化、语境提示与英语例句。词性按具体英文义项填写；未给出的字段不自动推断。

上游中文词库有 871 个词头具有多个无声调读音，其中不少包含罕见或古代读音。本轮为仍未整理的 1,675 个读音放置保护记录：隐藏词头通用释义，详情解释尚未整理，仍然可以正常输入中文。不能把同一英文释义复制到所有拼音。高频常用读音优先补齐；名字、古代读音和罕见义保留待办。

其他上游词条也能长按查看已有词性和短释义，并标明来源、未独立校审及语境限制。此路径不会自动生成原形、变位、可数性或例句；完整词典语法信息仍待增补。

## 数据审计口径

实际打包后的 mmap 表共 1,992 条，包含已整理读音与保护记录。逐条与源 JSON 核对，验证中文/英文 Unicode、词性及元数据完整性。

中文词库共 91,919 个不同词头。原英语表匹配 88,112 个；启用读音保护与新整理后，可显示英语释义的词头为 87,352 个，即约 95.0%。部分未整理多读音词主动隐藏，因此有效显示数量不能继续宣传为 88,112。

静态高频前 1,000 词有 982 个至少一个词库读音可显示释义，前 5,000 有 4,685 个。这些是词头数量覆盖，不是按使用频次加权，也不等于词义准确率。已有词头的其他读音可能仍缺释义。

所有新学习数据及原机器生成释义均未完成独立英语编辑校审；同一无声调拼音仍可能有不同声调和意义。短语表存在记录不等于其每种拼音输入/T9 路径或句子语境均已验证。当前产品是词级伴学，不提供整句翻译、语法纠错或完整变位引擎。
