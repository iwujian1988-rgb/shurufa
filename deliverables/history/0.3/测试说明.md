# 词伴 Android 0.3.0 Demo：开始测试

本次提供两个独立安装包，可同时安装：`ciban-english-demo.apk` 和 `ciban-french-demo.apk`。暂用名称“词伴”，英语蓝色、法语绿色。两者均以中文拼音输入为主，在候选旁显示对应语言释义。

适用配置：Android 8.0 及以上的 64 位设备；带 ARM64 手机架构和 x86_64 模拟器架构。0.1 在 Android 15 模拟器验收，0.2 在用户 Android 12 ARM64 手机上测试；更多系统和应用兼容尚未完成。当前是 debug 测试签名，正式发布和长期升级签名另做。

## 最快试用

1. 把 APK 传到手机安装；按手机提示允许当前文件管理器或浏览器安装这个测试包。
2. 打开“词伴 · 英语”或“词伴 · 法语”，直接使用页面下方的内置键盘试打，无需先启用系统输入法。
3. 输入 `nihao`，候选“你好”旁英语为 `hello · hi`，法语为 `bonjour`。点击中文候选，输入框应得到“你好”。
4. 再试 `xuexi`、`pengyou`、`kafei`。横滑浏览候选，点“展开”查看完整译词；缺少译词时显示“暂无释义”。
5. 点“中”切到字母模式，`123` 打开数字与符号，法语包提供 é、è、ê、à、ç、ù、œ。点删键删除，长按连续删除；空格确认首选，回车确认原文或执行输入框动作。

## 法语学习详情

法语版输入 yinhang，长按“银行”候选，可看到 la banque、名词阴性和原形 banque。输入 wojuede 后长按“我觉得”，可查看 je pense que… / je trouve que… 的用法。长按不输入中文；点“返回键盘”继续打字，点候选或详情的“输入中文”才上屏。详情可上下滚动，包含来源与未独立校审提示。

可再试 hai / huan 的“还”、hang / xing 的“行”、de 的“的”、buzhidao 的“不知道”。不同无声调拼音匹配对应词义；同一拼音的不同声调和整句语境仍需判断，不能把每个短译词当作万能替换。

## 九宫格

点候选栏上方“全键盘”切换到“九宫格”，再点即可切回；每版独立记住布局。中文模式下逐个按数字键：`64426` 是 `nihao`，`98394` 是 `xuexi`，`52334` 是 `kafei`。数字是正在输入的组合编码，选择中文候选才上屏中文。

横滑“选拼音”栏可指定音节，例如输入 `64426` 后点 `ni`，再选 `hao`；“分词”锁定推荐的下一音节，“重选”取消音节限制。`1 标点` 打开符号，`ABC` 返回当前中文布局。字母和密码输入使用全键字母界面。

每段九宫格最多 32 键，先选词再继续；未选词时回车按原文确认数字编码。九宫格复杂长句和简拼还需迭代。详细测试见 [九宫格验收记录](九宫格验收记录.md)。

## 在其他应用里用

应用中点“1 启用键盘”，在系统列表启用对应的词伴；返回点“2 选择键盘”，选英语或法语版本。点“系统键盘测试”可先在本应用输入框验证，再去笔记、浏览器、聊天等应用试用。键盘上的 ◎ 打开系统输入法切换面板。

两个版本可以一起启用、随时切换。数据各在各自应用的私有目录；核心输入和释义离线工作，APK 没有联网权限。密码输入直接输入字母或数字，不显示学习候选；应用声明“不个性化学习”时也关闭新增学习。

## 这轮最值得反馈的内容

- 首选中文是否符合预期，连续输入是否跟手，点击是否上屏正确。
- 译词在你手机上是否清楚，展开后长释义是否可读，法语重音是否正常。
- 删除、切换输入框、移动光标、回车发送、收起和再打开键盘是否异常。
- 深浅色、较大系统字体、横屏、不同应用中是否遮挡或出现误触。

若发现问题，记录手机型号、系统版本、英语或法语包、所在应用、复现输入串及实际结果即可。不要在问题材料中包含真实密码或私人聊天内容。

## 当前限制

法语基础数据与常用整理按读音匹配覆盖当前中文库 **34,548 个词**，常用学习层为 **529 个词/短语，含 144 条会话表达**。独立法语编辑校审尚未完成；未知词性、性别等保留未知，前五千尚有缺口。英语沿用上游机器生成释义。词级释义不等于整句翻译，没有语音、滑行、云 AI、完整法语纠错或词汇复习系统。

0.3 已完成原生回归、双包构建/lint、真实 mmap 数据审计、手机词库/学习数据升级验证及手机实际触摸验收。当前详细结果见 [法语词库验收记录](法语词库验收记录.md)；旧记录为历史基线。跨应用、长时间使用、直接编辑试打框与光标、性能和耗电仍待专项测试。
