# 0.2.0 九宫格验收记录

日期：2026 年 10 月 4 日。设备：用户 M2007J17C、Android 12 / API 31、ARM64；同机英语和法语独立包。

## 实现

- 九宫格数字键对应多字母拼音；使用真实中文词库构建数字索引、有界词路径搜索，再交给青简查询、释义和提交。
- 数字组合文本、横滑选择完整音节、分词/重选、候选展开、中文上屏、前缀提交保留剩余编码、删除/空格/回车。
- 顶部“全键盘 / 九宫格”切换，按产品记住布局；字母、密码和数字输入仍使用相应直接输入模式。
- 每段九宫格最多 32 个数字键；词路径最多保留 8 条，复杂长句与简拼体验还需完善。回车原文确认会提交数字编码；布局切回全键盘使用当前解析拼音。
- 未启用时点击“选择键盘”会提示并转到启用设置；MIUI“其他输入法”列表需要滚动。

手机 JNI 的五次数字输入耗时记录在日志中，仅计 JNI 调用；样本极少，不是按键到候选绘制的 p95，不据此宣称已达到性能目标。

触摸脚本在每次抓取后断言宿主输入文本，并额外连续发送按键验证队列。系统 IME 窗口的按键位置复用同类 KeyboardView 在同一手机的观测坐标，并以实际组合和上屏结果断言。截图直接来自这台手机，不是设计稿。

MIUI 拦截测试进程从后台启动 Activity 时，测试助手只用 adb 将词伴试打页带到前台，没有关闭系统保护或修改其他应用。早期助手重复清空 Activity 导致一次测试失败，已改成只启动一次并重新完成最终包测试；不能把该失败结果当作 PASS。
