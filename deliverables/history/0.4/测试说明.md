# 词伴 Android 0.4.0-demo 测试说明

英语、法语是两个独立安装包，支持 Android 8.0 及以上。手机上的原包可直接覆盖升级，保留原有学习数据。包及源码的最终 SHA-256 见 manifest.json / SHA256SUMS.txt。

## 开始试用

1. 打开对应的词伴应用，先启用，再在系统输入法选择器中选择词伴。
2. 已启用时应用优先显示试打输入框；可点“系统键盘测试”验证实际输入法。
3. 顶部“全键盘／九宫格”切换中文布局。九宫格输入 64426，选择“你好”；可点选拼音 ni、hao。
4. 应用内“九宫格高度”提供紧凑、舒适、加大，默认舒适。更改后，系统键盘下次显示时应用新高度。两个产品各自保存。
5. 普通点击候选输入中文；长按查看学习用法，返回后仍可提交原候选。详情内容较长时可以上下滚动。

## 英语重点

- yinhang → 银行：bank，长按查看可数性和复数 banks。
- haizi → 孩子：child，长按查看 children。
- xinxi → 信息：information，查看不可数名词用法。
- xuexi → 学习：learn / study，查看词形和例句。
- hai / huan → 还：分别 still / return；xing / hang → 行：分别行走或行列义。
- wojuede → 我觉得：I think… / I find…；buzhidao → 不知道：not know，例句示范完整否定句。
- 未整理的多读音候选可能显示“暂无释义”，长按说明原因；中文输入仍可正常提交。

## 法语回归

- yinhang → 银行：banque，长按查看阴性、原形和来源。
- hai / huan → 还：encore / rendre；xing / hang → 行：marcher / ligne。
- wojuede → 我觉得：je pense que… / je trouve que…，长按查看语境。

当前是离线词级伴学测试包；已提供的语言整理均未完成独立编辑校审。无声调拼音不能解决所有词义歧义，词级释义不等于整句翻译。详细测试证据与实际限制见“英语与键盘高度验收记录.md”，剩余开发见 docs/DEVELOPMENT_BACKLOG.md。
