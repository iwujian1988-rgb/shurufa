## 法语与中文候选

新增源表 data/french-priority.tsv 和显式读音表 french-priority-readings.json，878 个源记录中 1 个已有整理词保留，实际新增 877 条记录。真实 FrenchLexicon mmap 逐条读取核对短义；错误读音不能命中。法语冠词、词性和已知元数据保留；省略主语的表达使用明确语境说明。

冻结原始中文词库作为覆盖分母：91,919 词头中 35,235 命中，静态前千词 974/1000，前五千 4566/5000，尚缺 434 个；不是用户实际使用覆盖率，也不是内容准确率。新增 55 条日用中文词读音，全量原始词条/读音/频率一致性校验通过。新增频率 1000 为默认值，未宣称真实使用频次。

固定新增词验证：瓶盖 → le bouchon（瓶盖类型另有说明）；平菇 → le pleurote；保鲜膜 → le film alimentaire；充电宝 → la batterie externe。词库来源/许可独立保留：CFDICT 底库 CC-BY-SA-3.0，项目补充 GPL-3.0-or-later。AI 草拟、自查不是独立法语编辑审核，后者继续待办。

## 外观与交互

词伴专用浅/深色主题、细边框、较小阴影、字距行距、选中标记、五行浅色默认、语言分页提示已实现。候选首义显示、48 字符上限及省略，不改变完整译文上屏或第二义快捷提交。上游青简默认主题保持原行为。

设置首页包含启用、试打和“使用简洁浅色外观”；其他输入偏好折叠。新默认不覆盖已有配置，一键按钮用于升级用户。目标是接近微信输入法的简洁风格，未使用其品牌素材，未声称像素一致。
