# Windows 0.1.0-demo.2 测试说明

英语与法语为独立安装器，支持 Windows 11 x64，保留现有产品身份与配置路径。本轮安装器为未签名测试包；Defender 结果见配套验收记录，不保证所有安全软件零误报。

## 使用

1. 安装对应语言的 0.1.0-demo.2 EXE。安装过程中按系统提示处理正在使用的旧版；不要手动覆盖已加载 DLL。
2. 打开“词伴 · 法语设置”或英语设置，按首页启用指引，在 Windows 输入源选择对应产品。
3. 升级保留旧外观偏好。想应用本次效果，点击设置首页“使用简洁浅色外观”，采用浅色、竖排和五行候选。深色及其他偏好在“输入偏好”展开区。
4. 在首页试打，再到日常应用测试。先用瓶盖、平菇、保鲜膜、充电宝、苹果、银行等固定词检查中文候选及法语。
5. 空格提交中文，译词快捷键按当前配置使用。候选只展示首义的短内容；长译文省略不影响完整上屏，原第二义快捷键也保留。

## 本次变化

候选采用较紧凑的排版、细边框、柔和阴影、绿色选中标记和语言/分页提示。设置首页突出启用和试打，其他设置折叠。

法语新增 877 条有效记录，静态前五千词覆盖达到 4566/5000。另补 55 条中文日用词读音；并非所有中文候选都有法语，剩余缺口包括语境片段、专名与待校审项。本产品尚不提供任意整句翻译。词库未经独立法语编辑全量审核。
