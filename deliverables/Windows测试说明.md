# 词伴 Windows 测试版 0.1.0-demo.1

适用 Windows 11 x64。英法为两个独立安装包，可同时安装；本次没有更新安卓 APK 或官网领取规则。

1. 双击对应 EXE，按照安装向导完成正常管理员确认。完成页保留“启用词伴并打开设置与试打”。
2. 按 Win + 空格选择“词伴 · 英语”或“词伴 · 法语”。如果没有出现，打开开始菜单中的词伴设置，点击“在系统中启用词伴”；关闭后重开要输入文字的应用，必要时注销再登录。
3. 在普通权限记事本输入 nihao / pingguo / xiexie。候选右侧分别观察 hello / apple / thank you，或 bonjour / la pomme / merci。
4. 空格输入中文；Ctrl + 候选数字输入第一个译词；Shift + Ctrl + 数字输入第二个译词（存在时）。Esc 取消，Shift 切换中英，[] 翻页。设置首页有不保存内容的试打框。
5. 可在 Windows“已安装的应用”卸载。个人配置和学习记录分别保留在 %APPDATA%/CibanEnglish 与 CibanFrench。

已验证真实后台输入、x64 DLL COM 创建和英法词义提交；安装注册、跨应用输入、32 位宿主和设置页实际窗口尚未完成验收。当前不是正式发布版。词义使用与安卓相同的离线读音表；未覆盖的词可无译文。任意新词组整组翻译、法语自动纠错/变位、桌面长按学习详情尚未实现。

Microsoft Defender 最终安装包与解包扫描记录见 windows-evidence/antivirus.json。测试包未做商业代码签名，可能出现发布者未知/SmartScreen 信誉提示；不能保证所有杀毒软件零误报。如果报告明确威胁名称，请停止运行并反馈名称、截图和 SHA-256；无需关闭防护或加排除项。

本版本没有加壳、驱动、键盘钩子、证书导入或安全设置修改。中文输入及随包词义离线工作，云预测和输入内容日志默认关闭。未申请 uiAccess，管理员权限应用及个别系统/商店应用中候选可见性仍待验证。
