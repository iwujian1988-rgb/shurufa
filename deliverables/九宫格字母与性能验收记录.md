# 词伴 Android 0.5：字母九宫格与性能

日期：2026-10-04。双产品为 dev.ciban.english / dev.ciban.french，versionCode 5、versionName 0.5.0-demo。代码继续共享，语言数据沿用 0.4。当前 APK 与对应源码以 manifest.json / SHA256SUMS.txt 的哈希为准。

## 用户要求与实现

九宫格主键改为单行大号 ABC、DEF、GHI、JKL、MNO、PQRS、TUV、WXYZ（24sp），不显示 2–9 的数字标签；左上为标点。内部九宫格编码和无障碍键位编号保留，实际拼音映射不变。舒适高度、三档设置和数字模式保留，两包共用。

每键刷新改为复用候选卡。默认加载前八项，横滑到末端前加载后八项，全部候选仍可横滑和展开。完整展开列表按需创建。按下时捕获候选身份与 revision，刷新重绑定不能让抬手提交另一个词。

Rust 解码器启动时预建合法末音节补全前缀表，缓存音节数字编码，避免每键扫描大量不合法长词与重复编码。八条解析路径合并去重后才统一补译词。beam、候选上限及评分规则保持不变。

## 真机性能对比

设备：M2007J17C，Android 12 / API 31 / ARM64。使用同一 Debug 测量器、舒适九宫格、六组固定合成输入，在自己的试打页测试；private reset 不写入个人学习内容。不读取其他应用。

口径：从 performClick 到 raw 匹配的候选状态首次 keyboard onDraw 后回调，包含排队、JNI、JSON 解析、编辑器处理、视图绑定和首帧；排除物理触摸硬件及显示扫描。不是所有宿主的端到端延迟。每组两轮热身后取 UI 276 样本；独立 JNI 测量 460 样本。JNI 数字不可冒充 UI 时延。

| 指标 | 英语 0.4 基线 | 英语 0.5 | 法语 0.5 |
| --- | ---: | ---: | ---: |
| UI 首次绘制 p50 | 162.92ms | 39.03ms | 39.01ms |
| UI 首次绘制 p95 | 181.41ms | 71.41ms | 63.31ms |
| UI 首次绘制最大值 | 192.68ms | 95.09ms | 104.68ms |
| JNI p50 | 12.92ms | 6.67ms | 5.78ms |
| JNI p95 | 24.62ms | 14.69ms | 14.06ms |
| 十键连续触发到最终绘制 | 776.20ms | 155.17ms | 161.60ms |

英语 p95 减少约 60.6%，p50 减少约 76.0%；十键突发没有丢失或乱序。法语未测 0.4 基线，不能将英语的下降比例当作法语对比。此前讨论的 p95 <50ms 目标尚未达到；未验证所有输入长度、应用、冷启动、耗电及内存。

基线是 0.4 功能加 Debug 测量入口，非原 APK 的完全相同二进制；核对两种 ABI 原生库、中文词典、英文释义和学习表与原 0.4 APK 哈希一致，测量器源文件在前后相同。证据为 0.5-baseline-provenance.json、0.5-performance-english-baseline.json、0.5-performance-english-optimized.json、0.5-performance-french-optimized.json。所有当前性能记录绑定最终 APK 哈希。第一轮中间包结果已由最终包结果替换。

## 功能检查

- Rust 默认 13 项测试通过；额外针对实际随包词典的 1,522 个前缀/选音样本，与冻结 0.4 解码器的路径、分数、选音结果一致。这是抽样对照，不是全量组合穷举。fmt / all-targets clippy（-D warnings）通过。
- 双 ABI release 原生库、双 APK、双测试 APK 构建与 lint 通过。lint 只有既有工具版本提醒；APK 签名与 16K zipalign 检查通过，不等同 16K 实机内存页运行验收。
- Android 15 / API 35 x86_64 模拟器实际 JNI/UI 双包通过：全键与九宫格输入、译词、选音、提交、删除、过期候选拒绝、英法读音区分、长按语法详情；新增八个字母标签及“按下后视图被重新绑定仍发送旧候选代次”检查通过。
- 手机双包字母/候选功能六项通过：八个字母键、标点键；银行词义与语法、长按返回保留输入、展开提交；横滑加载超过前八项（英语 17、法语 14 个不同候选），再输入可刷新并正确提交“你好”。这不声称逐一触摸所有六十候选。
- 手机四项九宫格触摸与真实系统 IME 流程通过：英语/法语各试打与系统键盘，选 ni/hao、提交、删除、空格及连续按键。MIUI 的 UI dump 不暴露系统 IME 节点，因此系统触摸坐标来自已测量的共享试打键盘，结合 dumpsys 输入法状态、真实编辑器结果及截图确认。
- 覆盖安装保留两包学习文件，前后哈希一致；当前内容版本仍为英语 engine-v2-43a90a24aa9d11a0、法语 engine-v2-742f2adb46689862。没有卸载重装或修改手机安全设置。

功能原始记录：0.5-letters-phone-results.json、t9-phone-ui-results.json、0.5-emulator-english-jni.txt、0.5-emulator-french-jni.txt、0.5-t9-ranking.txt、data-upgrade-verification.json。旧 0.4 文档与截图属于历史，不证明新包全面验收。
