词伴 Windows 0.1.0-demo.1（Windows 11 x64）

1. 安装英语或法语包，也可同时安装。注册输入法需要正常的管理员确认。
2. 关闭后重新打开要输入文字的应用，按 Win + 空格选择“词伴 · 英语”或“词伴 · 法语”。
3. 输入 nihao、pingguo、xiexie，查看中文候选右侧的英文或法文。
4. 空格选中文；Ctrl + 候选数字输入第一个译词；Shift + Ctrl + 数字输入第二个译词（有第二个时）。Shift 切换中英，Esc 取消，[] 翻页。
5. 开始菜单 → 词伴设置与试打，可调整候选外观、字体、全拼/双拼等。

当前是本地测试版，尚无商业代码签名。Windows 可能提示发布者未知或信誉不足；这不等于已经检测到病毒。若安全软件明确报出威胁名称，请停止运行并把检测名称和文件哈希反馈给开发者，无需关闭防护或添加排除项。

本包使用标准 Windows TSF 和 Inno Setup，不使用加壳、混淆、驱动、键盘钩子、证书导入或安全设置修改。中文输入与随包词义离线工作，云预测和输入内容日志默认关闭；选用可选云服务后相应上下文会发到您指定的服务商。

未签名测试版不申请 uiAccess：个别系统/商店应用中候选窗口可能被遮挡，管理员权限应用不能保证兼容。先在普通权限记事本、浏览器和词伴试打页测试。任意新词组的整组翻译、法语自动纠错、完整语法/变位引擎不在本次 demo 中。

法语基础词典来源 CFDICT（CC BY-SA 3.0），英语基础释义来源青简随包表；项目学习词与短语为 AI 整理，尚未独立语言编辑校审。遇到多读音或缺释义时会优先避免显示错误翻译，空白不代表输入故障。

卸载：Windows 设置 → 应用 → 已安装的应用 → 词伴。卸载保留个人配置与学习记录；英法数据分别在 %APPDATA%\CibanEnglish 和 %APPDATA%\CibanFrench，互不覆盖。
