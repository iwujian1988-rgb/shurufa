# 词伴分支的 Android demo

这是基于固定青简源码新增的安卓客户端，客户端在仓库外层 `mobile/android/`，共享桥接在 `mobile/native/`。不是上游既有 Android 发布。

英语与法语独立安装，可在应用内直接试打，或通过系统设置启用并切换到对应键盘。点中文候选上屏中文；候选旁显示目标语言译词。法语目前是有限 AI 示例，缺释义会明确显示“暂无释义”。

26 键与九宫格拼音、展开候选、中文提交、字母模式、数字符号、删除和长按删除、回车、系统输入法切换、浅深色与震动设置为 demo 范围。候选栏上方点“全键盘 / 九宫格”切换布局；九宫格输入 `64426` 后选择“你好”，可横滑选拼音栏限定 `ni`、`hao`；每段最多 32 键，回车按原文确认数字编码。

Android 0.2 的双版在 M2007J17C / Android 12 ARM64 手机测试；全面真机兼容、复杂九宫格长句/简拼、法语词表校审及商店发布仍未完成。完整安装与验证记录在外层项目 `deliverables/` 和 `docs/`。
